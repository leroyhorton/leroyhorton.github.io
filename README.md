# LeRoy Horton — Portfolio

A simple one-page GitHub Pages portfolio for LeRoy Horton.

## Structure

- `index.html` — the complete portfolio page
- `styles.css` — responsive styling
- `script.js` — current-year footer only
- `assets/` — selected personal and project images
- `files/` — résumé and selected project reports

## Publish on GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
4. Save. GitHub will provide the site URL after deployment.

The site does not need a build step or framework.
